## 1. Create the profile repository

GitHub only displays a profile README when the public repository name exactly matches your username and it contains a non-empty `README.md` in its root.

Create:

`https://github.com/new`

Repository name:

`msaad-20007`

Set it to **Public**.

Then upload everything from this folder.

## 3. Enable Actions write permission

The workflow needs permission to commit the generated visual.

Repository:

Settings → Actions → General → Workflow permissions

Choose:

**Read and write permissions**

Save.

Then go to:

Actions → Refresh profile visuals → Run workflow

The workflow also runs on a daily schedule.
